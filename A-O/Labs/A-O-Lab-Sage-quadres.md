# Квадратичные вычеты и закон взаимности

**Определения**

* Пусть $p$ — нечётное простое. Число $a$, $p\nmid a$, — *квадратичный вычет* по модулю $p$, если сравнение $x^2\equiv a\pmod p$ разрешимо, и *квадратичный невычет* в противном случае. Среди $1,\dots,p-1$ ровно $(p-1)/2$ вычетов и столько же невычетов.
* *Символ Лежандра*: $\left(\frac ap\right)=0$ при $p\mid a$, $1$ для вычета и $-1$ для невычета. *Критерий Эйлера*: $\left(\frac ap\right)\equiv a^{(p-1)/2}\pmod p$. Символ мультипликативен: $\left(\frac{ab}p\right)=\left(\frac ap\right)\left(\frac bp\right)$, и зависит только от $a\bmod p$.
* *Квадратичный закон взаимности*: для различных нечётных простых $p,q$ выполнено $\left(\frac pq\right)\left(\frac qp\right)=(-1)^{\frac{p-1}2\cdot\frac{q-1}2}$; кроме того, $\left(\frac{-1}p\right)=(-1)^{\frac{p-1}2}$ и $\left(\frac2p\right)=(-1)^{\frac{p^2-1}8}$.
* $n(p)$ — *наименьший квадратичный невычет* по модулю $p$; это всегда простое число. *Первообразный корень* по модулю $p$ — образующая циклической группы $\mathbb{F}_p^*$; $g(p)$ — наименьший первообразный корень. Каждый первообразный корень является квадратичным невычетом.
* *Гипотезы Виноградова*: для любого $\varepsilon>0$ выполнено $n(p)=O(p^{\varepsilon})$ и $g(p)=O(p^{\varepsilon})$. Безусловно известна оценка $n(p)=O(p^{1/(4\sqrt e)+\varepsilon})$ (Бёрджесс); при обобщённой гипотезе Римана $n(p)<2(\ln p)^2$ (Бах).
* *Сумма характера*: $S_p(x)=\sum_{n\le x}\left(\frac np\right)$. *Неравенство Пойа–Виноградова*: $|S_p(x)|\le\sqrt p\ln p$ при всех $x$.
* *Число классов* $h(-p)$ — число классов идеалов поля $\mathbb{Q}(\sqrt{-p})$ (для $p\equiv3\pmod4$, $p>3$). Если $p\equiv1\pmod4$, то $\left(\frac{-1}p\right)=1$, символ чётен по $n\mapsto p-n$ и $S_p\big(\tfrac{p-1}2\big)=0$. Если $p\equiv3\pmod4$, $p>3$, то по формуле Дирихле $S_p\big(\tfrac{p-1}2\big)=\big(2-\left(\tfrac2p\right)\big)h(-p)>0$.

**Задание**

* Для нескольких $p$ найти множество квадратичных вычетов (`quadratic_residues`), проверить критерий Эйлера и мультипликативность символа Лежандра (`legendre_symbol`). Изобразить последовательность $\left(\frac np\right)$, $1\le n<p$, и сравнить её с последовательностью независимых случайных знаков $\pm1$ по распределению длин серий.
* Построить таблицу значений $\left(\frac pq\right)$ и $\left(\frac qp\right)$ для нечётных простых $p,q$ из небольшого диапазона (`legendre_symbol`), найти связывающую их закономерность и сравнить с квадратичным законом взаимности. Аналогично найти правила для $\left(\frac{-1}p\right)$ и $\left(\frac2p\right)$.
* Для простых $p$ из достаточно большого диапазона вычислить $n(p)$, построить график $n(p)$ в зависимости от $\ln p$, найти рекордные значения (простые $p$, для которых $n(p)>n(q)$ при всех простых $q<p$) и отношение $n(p)/(\ln p)^2$; сравнить с оценкой Баха и гипотезой Виноградова. Найти доли простых с $n(p)=2$, $3$, $5$ и объяснить их с помощью квадратичного закона взаимности. (Cython)
* Вычислить $g(p)$, проверяя на первообразность числа $2,3,\dots$ по порядку; найти рекордные значения (в том же смысле) и сравнить рост $g(p)$ и $n(p)$. Проверить для $p$ из достаточно большого диапазона, что $n(p)\le g(p)$, и объяснить, почему это неравенство выполняется всегда. (Cython)
* Для нескольких больших $p$ построить график $S_p(x)$, $0\le x<p$, вычислить $\max_x|S_p(x)|/(\sqrt p\ln p)$ и проверить неравенство Пойа–Виноградова. Отдельно рассмотреть $p\equiv1$ и $p\equiv3\pmod4$ и объяснить различие значений $S_p((p-1)/2)$; для $p\equiv3\pmod4$ сверить значение с $\big(2-\left(\frac2p\right)\big)h(-p)$ (`QuadraticField(-p).class_number()`).
* Подсчитать число каждой из четырёх пар $\big(\left(\frac np\right),\left(\frac{n+1}p\right)\big)$ при $1\le n\le p-2$. Для шаблонов из $k=3,4,5$ подряд идущих символов сравнить число вхождений с $p/2^k$ и исследовать зависимость отклонения от $p$ (ожидается отклонение порядка $\sqrt p$).
