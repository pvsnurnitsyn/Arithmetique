# Тесты простоты и псевдопростые числа

**Определения**

* Составное $n$ называется *псевдопростым по основанию $a$*, где $\gcd(a,n)=1$, если $a^{n-1}\equiv1\pmod n$.
* *Число Кармайкла* (Carmichael number) — составное $n$, псевдопростое по любому основанию $a$, взаимно простому с $n$.
* *Критерий Корсельта*: составное $n$ является числом Кармайкла тогда и только тогда, когда $n$ свободно от квадратов и $p-1\mid n-1$ для каждого простого $p\mid n$.
* Пусть $n$ нечётно и $n-1=2^s t$, $t$ нечётно. Число $n$ *сильно псевдопростое по основанию $a$* (strong pseudoprime), если $a^t\equiv1\pmod n$ или $a^{2^r t}\equiv-1\pmod n$ для некоторого $0\le r<s$. Если $n$ составное и выполняет это условие, основание $a$ называется *сильным лжесвидетелем* (strong liar). Тест Миллера–Рабина проверяет это условие для нескольких случайных оснований.
* *Теорема Монье–Рабина*: для нечётного составного $n>9$ доля сильных лжесвидетелей среди $1\le a<n$ не превосходит $1/4$.

**Задание**

* Реализовать тест Ферма через `power_mod`. Найти все псевдопростые по основанию $2$ до $N$ (достаточно большое) и сравнить их количество с числом простых до $N$. (Cython)
* Найти числа Кармайкла до $N$ по определению. Проверить для них критерий Корсельта, используя `factor`, и проверить, что у каждого найденного числа не менее трёх простых делителей.
* Реализовать проверку условия сильной псевдопростоты по заданному основанию. Для составных $n$ из диапазона вычислить долю сильных лжесвидетелей, построить её распределение, найти $n$ с наибольшей долей и сравнить с оценкой Монье–Рабина. (Cython)
* Сравнить результаты с `is_prime` и `is_pseudoprime` и по документации Sage/PARI выяснить, какие тесты используют эти функции.
