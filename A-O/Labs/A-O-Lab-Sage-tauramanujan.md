# Функция Рамануджана $\tau(n)$

**Определения**

* Пусть $q=e^{2\pi iz}$. *Функция Рамануджана* $\tau(n)$ определяется разложением
  $$\Delta(z)=q\prod_{n\ge1}(1-q^n)^{24}=\sum_{n\ge1}\tau(n)q^n=q-24q^2+252q^3-1472q^4+4830q^5-\cdots.$$
* Для целого $k$ положим $\sigma_k(n)=\sum_{d\mid n}d^k$, а $d(n)=\sigma_0(n)$ — число делителей $n$. *Ряды Эйзенштейна* $E_4=1+240\sum_{n\ge1}\sigma_3(n)q^n$ и $E_6=1-504\sum_{n\ge1}\sigma_5(n)q^n$ связаны с $\Delta$ тождеством $1728\,\Delta=E_4^3-E_6^2$.
* *Тождество Рамануджана*: для $n\ge1$
  $$\tau(n)=\frac{65}{756}\sigma_{11}(n)+\frac{691}{756}\sigma_5(n)-\frac{691}{3}\sum_{k=1}^{n-1}\sigma_5(k)\sigma_5(n-k).$$
* *Теорема Морделла*: $\tau(mn)=\tau(m)\tau(n)$ при $\gcd(m,n)=1$ и $\tau(p^{k+1})=\tau(p)\tau(p^k)-p^{11}\tau(p^{k-1})$ для простого $p$ и $k\ge1$.
* *Сравнение Рамануджана*: $\tau(n)\equiv\sigma_{11}(n)\pmod{691}$.
* Оценки. *Теорема Гекке* (простая оценка): $|\tau(n)|\le Cn^{6}$ с некоторой константой $C$. *Теорема Делиня* (гипотеза Рамануджана): $|\tau(p)|\le2p^{11/2}$; вместе с теоремой Морделла она даёт $|\tau(n)|\le d(n)\,n^{11/2}$. Для простого $p$ можно записать $\tau(p)=2p^{11/2}\cos\theta_p$ с однозначно определённым $\theta_p\in[0,\pi]$.
* *Теорема Ранкина*: существует константа $C>0$ такая, что $\sum_{n\le x}\tau(n)^2\sim Cx^{12}$ при $x\to\infty$.
* *Мера Сато–Тейта* — вероятностная мера на $[0,\pi]$ с плотностью $\frac2\pi\sin^2\theta$; в переменной $x=\cos\theta\in[-1,1]$ её плотность равна $\frac2\pi\sqrt{1-x^2}$. Нечётные моменты этой меры равны нулю, а моменты порядка $2m$ равны $C_m/4^m$, где $C_m$ — числа Каталана $1,2,5,14,\dots$ ($\tfrac14,\tfrac18,\tfrac5{64},\dots$). Теорема Барнет-Лэмба, Джеральди, Харриса и Тейлора (2011): углы $\theta_p$ равномерно распределены относительно этой меры.
* *Гипотеза Лемера*: $\tau(n)\ne0$ для всех $n\ge1$.

**Задание**

* Вычислить $\tau(n)$ до достаточно большого $N$ двумя способами: `delta_qexp` и перемножением $q\prod(1-q^n)^{24}$ в `PowerSeriesRing`. Убедиться, что результаты совпадают (контрольные значения: $\tau(1),\dots,\tau(7)=1,-24,252,-1472,4830,-6048,-16744$), и сравнить время работы. Вычислить также $(E_4^3-E_6^2)/1728$ и проверить совпадение с $\Delta$.
* Проверить тождество Рамануджана для $\tau(n)$ при $n$ из некоторого диапазона.
* Проверить на вычисленных значениях мультипликативность и рекуррентное соотношение для степеней простых.
* Проверить сравнение по модулю $691$. Экспериментально найти, по каким степеням $2$, $3$, $5$ и $7$ выполняются сравнения $\tau(n)\equiv\sigma_{11}(n)$ (возможно, только для $n$ из некоторых классов вычетов) и сравнить результаты для разных простых. Учесть, что максимальная степень, найденная в конечном диапазоне, может оказаться завышенной.
* Выяснить, для каких $n$ значение $\tau(n)$ нечётно, и сформулировать закономерность. Для малых простых $\ell$ (например, $\ell\le30$) найти классы вычетов $n\bmod\ell$, для которых $\tau(n)\equiv0\pmod\ell$ при всех таких $n$ из диапазона, и сравнить результаты для разных $\ell$.
* Проверить оценки: $|\tau(n)|\le d(n)\,n^{11/2}$ при всех $n\le N$ (в частности, границу Делиня $|\tau(p)|\le2p^{11/2}$) и более слабую оценку $|\tau(n)|\le Cn^6$. Построить графики отношений $|\tau(n)|/n^{11/2}$ и $|\tau(n)|/(d(n)n^{11/2})$, выяснить, насколько близко значения подходят к границе и при каких $n$.
* Построить гистограмму $\cos\theta_p$ по простым $p\le N$ и сравнить её с плотностью Сато–Тейта, в том числе по первым моментам; проследить, как улучшается совпадение с ростом $N$ (вещественные значения $\cos\theta_p$ вычислять с достаточной точностью, например в `RealField`).
* Проверить теорему Ранкина: построить отношение $\sum_{n\le x}\tau(n)^2/x^{12}$ в зависимости от $x$, оценить предельное значение и обсудить, насколько быстро отношение стабилизируется.
* Проверить гипотезу Лемера при $n\le N$. Объяснить с помощью мультипликативности, почему достаточно проверять значения $\tau(p^k)$ для степеней простых, и проверить отдельно, что $\tau(p^k)\ne0$ для небольших $p$ и $k$.
