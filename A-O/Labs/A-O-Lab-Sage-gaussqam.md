# Гауссовы целые и QAM

**Определения**

* *Гауссовы целые* — кольцо $\mathbb{Z}[i]=\{a+bi:\ a,b\in\mathbb{Z}\}$ с *нормой* $N(a+bi)=a^2+b^2$ (мультипликативной). Обратимые элементы: $\pm1,\pm i$. Кольцо $\mathbb{Z}[i]$ евклидово, поэтому в нём есть НОД и однозначное разложение на простые с точностью до обратимых.
* *Разложение рациональных простых в $\mathbb{Z}[i]$*: $2=-i(1+i)^2$; простое $p\equiv3\pmod4$ остаётся простым в $\mathbb{Z}[i]$; простое $p\equiv1\pmod4$ раскладывается как $p=\pi\bar\pi$ с неассоциированными простыми $\pi,\bar\pi$. Отсюда следует теорема Ферма: нечётное простое $p$ представимо в виде $a^2+b^2$ тогда и только тогда, когда $p\equiv1\pmod4$, и тогда $p=N(\pi)$ для $\pi=a+bi$.
* *Сигнальное созвездие QAM* (квадратурная амплитудная модуляция, quadrature amplitude modulation) из $M=4^k$ точек — множество $\{a+bi: a,b\in\{\pm1,\pm3,\dots,\pm(\sqrt M-1)\}\}$, то есть точки сдвинутой решётки $2\mathbb{Z}[i]+(1+i)$, лежащие в квадрате. Каждая точка кодирует $\log_2M$ бит.
* *Минимальное расстояние* $d_{\min}$ — наименьшее расстояние между точками созвездия. *Средняя энергия* $E_s$ — среднее значение $|s|^2$ по точкам созвездия.
* *Канал с аддитивным белым гауссовским шумом* (AWGN): принятый сигнал $r=s+w$, где $w=w_1+iw_2$, а $w_1,w_2\sim\mathcal N(0,\sigma^2)$ независимы. *Отношение сигнал/шум* $\mathrm{SNR}=E_s/(2\sigma^2)$ обычно выражают в децибелах: $10\log_{10}\mathrm{SNR}$.
* *Декодирование по максимуму правдоподобия* (maximum likelihood decoding) в канале AWGN — выбор ближайшей к $r$ точки созвездия; для QAM это округление каждой координаты до ближайшего допустимого значения (значения вне диапазона отображаются в крайние). *Вероятность ошибки на символ* (symbol error rate) $P_e$ — доля неверно декодированных символов.
* *$Q$-функция*: $Q(x)=\frac1{\sqrt{2\pi}}\int_x^\infty e^{-t^2/2}\,dt$ — вероятность того, что стандартная нормальная величина превзойдёт $x$ (выражается через `erfc`). Для квадратного QAM с $M=4^k$ точками и декодированием округлением координат ошибки по двум координатам независимы, и
  $$P_e=1-(1-P_1)^2,\qquad P_1=2\Big(1-\frac1{\sqrt M}\Big)\,Q\!\left(\sqrt{\frac{3\,\mathrm{SNR}}{M-1}}\right),$$
  где $P_1$ — вероятность ошибки по одной координате, а $\mathrm{SNR}$ берётся в линейном (не децибельном) масштабе.

**Задание**

* Для простых $p$ из достаточно большого диапазона найти разложение в $\mathbb{Z}[i]$ (`GaussianIntegers()`, `factor`) и классифицировать простые по $p\bmod4$. Найти НОД нескольких пар гауссовых целых с помощью `gcd` и проверить делимость.
* Для простых $p\equiv1\pmod4$ найти представление $p=a^2+b^2$ тремя способами: перебором, через разложение $p$ в $\mathbb{Z}[i]$ и с помощью `two_squares`. Сравнить время работы для $p$ растущей длины: перебор применим лишь до некоторой границы, определить её экспериментально, а два других способа исследовать для значительно больших $p$. (Cython)
* Построить и изобразить созвездия QAM для $M=4,16,64$ как подмножества $2\mathbb{Z}[i]+(1+i)$, вычислить $d_{\min}$, $E_s$ и отношение $d_{\min}^2/E_s$ и объяснить, как оно меняется с ростом $M$.
* Смоделировать передачу достаточно большого числа случайных символов по каналу AWGN при разных значениях SNR (в децибелах), декодировать округлением и построить график зависимости $P_e$ от SNR в логарифмическом масштабе для трёх созвездий. Диапазон SNR и число символов подобрать для каждого созвездия так, чтобы при каждом значении SNR наблюдалось достаточно ошибок для надёжной оценки $P_e$; точки, в которых ошибок не наблюдалось, не наносить на график (или указывать для них только верхнюю оценку). Сравнить результат с теоретической формулой $P_e$ для QAM из определений. (Cython)
