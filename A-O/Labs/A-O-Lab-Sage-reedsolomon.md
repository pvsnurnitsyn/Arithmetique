# Коды Рида–Соломона

**Определения**

* *Идея помехоустойчивого кодирования.* Сообщение передаётся по каналу, который может исказить часть символов. Чтобы получатель смог восстановить сообщение, к нему добавляют избыточность: сообщение из $k$ символов отображают в *кодовое слово* из $n>k$ символов (*кодирование*) так, чтобы разные кодовые слова сильно отличались друг от друга. Получатель по искажённому слову ищет ближайшее кодовое слово (*декодирование*). *Код* — множество кодовых слов $C\subset A^n$ над некоторым алфавитом $A$; число $k/n$ называется *скоростью* кода. Простейший пример: код повторения над алфавитом $\{0,1\}$, $0\mapsto000$, $1\mapsto111$; при приёме выбирается символ, встретившийся не менее двух раз, поэтому исправляется одна ошибка, но скорость равна лишь $1/3$.
* *Двоичный код* — код над алфавитом $\{0,1\}=\mathbb{F}_2$ (биты). *Код над конечным полем $\mathbb{F}_q$* ($q$ — степень простого) — код, у которого символами служат элементы $\mathbb{F}_q$; их можно складывать и умножать, что позволяет строить коды алгебраически (с помощью линейной алгебры и многочленов). Если $q=2^m$, то элемент $\mathbb{F}_{2^m}$ записывается $m$ битами, и слово длины $n$ над $\mathbb{F}_{2^m}$ превращается в двоичное слово длины $mn$. При этом любое число искажённых битов внутри одного символа считается одной ошибкой, поэтому такие коды хорошо исправляют *пакеты* (подряд идущие) ошибок; на этом основано их применение, например, в компакт-дисках и QR-кодах.
* *Линейный код* $[n,k]$ над $\mathbb{F}_q$ — подпространство $C\subset\mathbb{F}_q^n$ размерности $k$; его элементы называются *кодовыми словами*. *Расстояние Хэмминга* $d(\mathbf x,\mathbf y)$ — число координат, в которых $\mathbf x$ и $\mathbf y$ различаются. *Минимальное расстояние* $d$ кода — наименьшее расстояние между различными кодовыми словами (для линейного кода — наименьшее число ненулевых координат у ненулевого кодового слова). Код $[n,k,d]$ исправляет любые $t\le\lfloor(d-1)/2\rfloor$ ошибок.
* *Граница Синглтона*: $d\le n-k+1$ для любого линейного кода $[n,k,d]$. Коды, для которых достигается равенство, называются *кодами с максимальным достижимым расстоянием* (MDS codes).
* *Код Рида–Соломона*: для различных $\alpha_1,\dots,\alpha_n\in\mathbb{F}_q$ ($n\le q$) $\mathrm{RS}_k=\{(f(\alpha_1),\dots,f(\alpha_n)): f\in\mathbb{F}_q[x],\ \deg f<k\}$. Сообщение $(m_0,\dots,m_{k-1})\in\mathbb{F}_q^k$ кодируется многочленом $f(x)=m_0+m_1x+\dots+m_{k-1}x^{k-1}$. В *обобщённом коде Рида–Соломона* (generalized Reed–Solomon code) координаты умножаются на фиксированные ненулевые множители: $(v_1f(\alpha_1),\dots,v_nf(\alpha_n))$.
* *Теорема.* Код $\mathrm{RS}_k$ (а также обобщённый) — линейный код $[n,k,n-k+1]$, то есть MDS-код. *Идея доказательства*: ненулевой многочлен степени $<k$ имеет не более $k-1$ корней, поэтому у ненулевого кодового слова не более $k-1$ нулевых координат и не менее $n-k+1$ ненулевых; отсюда $d\ge n-k+1$, а граница Синглтона даёт обратное неравенство. Следовательно, код исправляет любые $t\le\lfloor(n-k)/2\rfloor$ ошибок.
* *Порождающая матрица* кода — матрица размера $k\times n$, строки которой образуют базис кода.

**Задание**

* Построить коды Рида–Соломона над $\mathbb{F}_{q}$ при $q=7,16,31$ и нескольких $n,k$ (`codes.GeneralizedReedSolomonCode`). Выписать порождающую матрицу и объяснить её строки как значения мономов $1,x,\dots,x^{k-1}$ в точках $\alpha_i$.
* Закодировать сообщение вручную (как вычисление многочлена) и с помощью `encode` и сверить результаты.
* Для малых параметров найти минимальное расстояние перебором кодовых слов и проверить, что оно равно $n-k+1$. Проверить по документации, не использует ли для кодов Рида–Соломона метод `minimum_distance` готовую формулу $n-k+1$ (в этом случае проверка ничего не доказывает); для честной проверки реализовать перебор самостоятельно или построить `codes.LinearCode` по порождающей матрице.
* Исправлять случайные ошибки встроенными декодерами (`decoders_available`, например декодеры Берлекэмпа–Велча и Гао). Для каждого числа ошибок $t=0,1,\dots,n-k$ оценить долю успешного декодирования, сравнить с границей $\lfloor(n-k)/2\rfloor$ и описать поведение декодеров за её пределами.
