# Группа $(\mathbb{Z}/n\mathbb{Z})^*$ и дискретный логарифм

**Определения**

* *Порядок* элемента $a\in(\mathbb{Z}/n\mathbb{Z})^*$ — наименьшее $k>0$ с $a^k\equiv1$. *Первообразный корень* по модулю $n$ — элемент порядка $\varphi(n)$. Первообразный корень существует тогда и только тогда, когда $n\in\{1,2,4,p^k,2p^k\}$, где $p$ — нечётное простое.
* *Гипотеза Артина*: если $a\ne-1$ и $a$ не является полным квадратом, то $a$ — первообразный корень по модулю бесконечного множества простых $p$. Ожидаемая плотность таких $p$ среди всех простых задаётся следующим образом. Пусть $C=\prod_p\big(1-\frac1{p(p-1)}\big)\approx0{,}3739$ — *константа Артина*, и пусть $a>1$ свободно от квадратов. Тогда
  * если $a\not\equiv1\pmod4$, плотность равна $C$ (в частности, для $a=2$ и $a=3$);
  * если $a\equiv1\pmod4$, плотность равна $\Big(1-\mu(a)\prod_{q\mid a}\frac1{q^2-q-1}\Big)C$, где $q$ пробегает простые делители $a$; например, для $a=5$ это $\frac{20}{19}C\approx0{,}3936$. Отличие от $C$ связано с тем, что при $a\equiv1\pmod4$ поле $\mathbb{Q}(\sqrt a)$ содержится в круговом поле $\mathbb{Q}(\zeta_{|a|})$, и условия по разным простым делителям перестают быть независимыми.

  Для $a$, не свободных от квадратов, плотность вычисляется сложнее; для полных квадратов она равна нулю.
* *Дискретный логарифм* $h$ по основанию $g$, где $g$ порождает $\mathbb{F}_p^*$, — такое $x$, что $g^x=h$.
* *Протокол Диффи–Хеллмана*: числа $p,g$ открыты; Алиса выбирает секретное $a$ и публикует $g^a$, Боб выбирает секретное $b$ и публикует $g^b$; общий секрет $g^{ab}=(g^b)^a=(g^a)^b$.
* *Безопасное простое* (safe prime) — простое вида $p=2q+1$ с простым $q$. Число называется *гладким* (smooth), если все его простые делители малы.
* *Алгоритм Полига–Хеллмана*: если $p-1=\prod q_i^{e_i}$, то задача дискретного логарифма в $\mathbb{F}_p^*$ сводится к задачам в подгруппах порядков $q_i^{e_i}$, а ответ собирается по китайской теореме об остатках.

**Задание**

* Для $n\le200$ построить $(\mathbb{Z}/n\mathbb{Z})^*$ (`Zmod(n).unit_group()`), найти её разложение в произведение циклических групп, определить, при каких $n$ существует первообразный корень, и сравнить с теоремой.
* Для $p<10^6$ найти долю простых, для которых $2$ — первообразный корень (`Mod(2,p).multiplicative_order()`), построить её зависимость от границы и сравнить с константой Артина $C$. Сделать то же для $a=3$ (ожидается $C$) и $a=5$ (ожидается $\frac{20}{19}C$, а не $C$; объяснить это отличие). Показать, почему для $a=4$ ответ другой: $4=2^2$ — квадрат, поэтому его порядок по модулю $p>3$ делит $(p-1)/2$ и доля равна нулю.
* Реализовать протокол Диффи–Хеллмана и показать, как противник, умеющий вычислять дискретный логарифм, находит общий секрет.
* Сравнить время работы `discrete_log` для простых $p$ одной длины с гладким $p-1$ и для безопасных простых, объяснить разницу с помощью алгоритма Полига–Хеллмана и сформулировать требование к выбору $p$.
