# Решёточные коды для гауссовского канала

**Определения**

* *Канал AWGN* в $\mathbb{R}^n$: $\mathbf r=\mathbf c+\mathbf w$, координаты $\mathbf w$ независимы и имеют распределение $\mathcal N(0,\sigma^2)$.
* *Решёточное декодирование*: по $\mathbf r$ находится ближайшая точка решётки $L$ (задача о ближайшем векторе, closest vector problem, CVP). Ошибка декодирования происходит, когда $\mathbf w$ выходит за пределы ячейки Вороного $V(L)$.
* При сравнении решётки нормируют на одинаковую плотность точек: $\mathrm{vol}(L)=1$, где $\mathrm{vol}(L)$ — объём фундаментальной области. *Номинальный выигрыш от кодирования* (nominal coding gain) решётки $L$ — величина $\lambda_1(L)^2/\mathrm{vol}(L)^{2/n}$, где $\lambda_1(L)$ — длина кратчайшего ненулевого вектора; для $\mathbb{Z}^n$ она равна $1$. Обычно её выражают в децибелах.
* *Нормированный второй момент* (normalized second moment) ячейки Вороного: $G(L)=\frac1n\cdot\frac{\int_{V(L)}|\mathbf x|^2d\mathbf x}{\mathrm{vol}(L)^{1+2/n}}$. Это средняя квадратичная ошибка квантования (замены точки $\mathbb{R}^n$ ближайшей точкой $L$) в расчёте на одну координату при единичном объёме ячейки. Для $\mathbb{Z}^n$ $G=1/12$; чем меньше $G$, тем лучше решётка как квантователь. Так как ошибка квантования равномерно распределённой точки фундаментальной области имеет то же распределение, что и для равномерной точки ячейки Вороного, $G$ можно оценивать по точкам фундаментальной области.
* *Явные координаты решёток.* $\mathbf D_n=\{\mathbf x\in\mathbb{Z}^n:\ x_1+\dots+x_n\ \text{чётно}\}$, $\mathrm{vol}(\mathbf D_n)=2$, $\lambda_1^2=2$. $\mathbf E_8=\mathbf D_8\cup\big(\mathbf D_8+(\tfrac12,\dots,\tfrac12)\big)$, $\mathrm{vol}(\mathbf E_8)=1$, $\lambda_1^2=2$.
* *Быстрые декодеры* (Конвей–Слоэн, 1982). Для $\mathbb{Z}^n$ — округление каждой координаты. Для $\mathbf D_n$: округлить все координаты; если сумма результата нечётна, пересчитать координату с наибольшей ошибкой округления, округлив её в другую сторону. Для $\mathbf E_8$: найти ближайшие точки в $\mathbf D_8$ и в $\mathbf D_8+(\tfrac12,\dots,\tfrac12)$ и выбрать более близкую.

**Задание**

* Вычислить номинальный выигрыш от кодирования в дБ для $\mathbf D_4$, $\mathbf D_8$ и $\mathbf E_8$.
* Реализовать быстрые декодеры из определений для $\mathbb{Z}^8$, $\mathbf D_8$, $\mathbf E_8$ и проверить их на небольшом числе случайных точек сравнением с декодированием общим методом для ближайшего вектора (например, `closest_vector` для решётки с целым базисом, если подходящее масштабирование координат позволяет её использовать). Реализовать моделирование: передаётся точка $\mathbf 0$ (в силу симметрии этого достаточно), добавляется шум $\mathbf w$, выполняется декодирование. Нормировку $\mathrm{vol}=1$ учитывать масштабированием $\sigma$ (например, для $\mathbf D_8$ с $\mathrm{vol}=2$ в этих координатах). Построить зависимость вероятности ошибки от $\sigma$ для $\mathbb{Z}^8$, $\mathbf D_8$ и $\mathbf E_8$. Диапазон $\sigma$ и число отсчётов подобрать так, чтобы вероятность ошибки менялась от близкой к единице до малых, но ещё надёжно измеряемых значений. При фиксированной вероятности ошибки оценить выигрыш решётки $L$ по сравнению с $\mathbb{Z}^8$ в дБ по формуле $20\log_{10}(\sigma_L/\sigma_{\mathbb{Z}^8})$ (где $\sigma$ — шум, при котором достигается выбранная вероятность ошибки) и сравнить его с номинальным. Объяснить различие с помощью контактного числа $\tau(L)$ (ожидается, что выигрыш при умеренных вероятностях ошибки меньше номинального). (Cython)
* Оценить $G(L)$ для $\mathbb{Z}^n$, $\mathbf A_2$, $\mathbf D_4$, $\mathbf E_8$ методом Монте-Карло (равномерно распределённые точки в фундаментальной области и расстояние до ближайшей точки решётки) с доверительными интервалами и сравнить с табличными значениями нормированного второго момента из книги Конвея–Слоэна. (Cython)
