# Дополнительные главы арифметики

Доп. главы — пока не спецкурс как таковой, а набор разделов, которые по тем или иным причинам не вошли в основные спецкурсы [A-I – A-IV](/README.md). Предполагается, что лекции будут проходить в формате летних и зимних факультативов, материалы по разделам будут появляться по мере проведения таких мини-курсов.
