# Дополнительные главы арифметики

Доп. главы — не спецкурс как таковой, а набор разделов, которые по тем или иным причинам не вошли в основные курсы [A-I – A-IV](/README.md). Лекции будут проходить в формате летних и зимних факультативов, материалы по разделам будут появляться по мере проведения таких мини-курсов.
